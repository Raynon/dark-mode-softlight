# 暗黑模式 · 大面积文案柔光降白

**系统开着深色模式，网页正文却还是一整片纯白、看着刺眼？**

这个脚本把大面积正文压暗一档（默认 80% 亮度）—— 按钮、链接、输入框、代码块、高亮、黑幕都不动。

**安装** → <https://greasyfork.org/scripts/588400>
（先装 Tampermonkey / Violentmonkey 等脚本管理器）

**用法** —— 脚本管理器菜单里两个命令：

- `🔆 全站文字亮度` —— 调当前**网站**的亮度（10–100，默认 80，设置后长期记住）
- `🚫 本页压暗开关` —— 让当前**页面**不压暗

**看看效果（在线测试页）** —— 系统/浏览器切到深色模式后打开，点「运行检查」会逐条对比"脚本生效前 / 后"的颜色：

👉 <https://raynon.github.io/dark-mode-softlight/test-cases.html>

页面上每一行都标了**期望**：哪些文字该被压暗（大面积正文、标题），哪些必须保持原样（链接、按钮、导航、面包屑、标签页、角标、代码高亮、黑幕、透明文字、行内强调色……）。

**常见问题**

- 压了反而更难读 → 那站大概是白底浅色主题，点 `🚫 本页压暗开关` 关掉
- 有的页面完全没变化 → 只在系统／浏览器深色模式下生效；少数自定义组件压不到（宁可漏压，不可误伤）
- 有些文字**没被压暗**（彩色的强调字、代码块里的高亮）→ 故意的：脚本只压大面积白字，强调色与语法高亮一律保持原样；**标题**则按"站点有没有自己给颜色"判定 —— 没给色的标题跟正文一起压暗，站点声明成亮白的标题（2.3.0 起）也会被压
- 单页应用换页面后要再点一次菜单 → 已知限制
- 和别的深色脚本打架 → 一般以最后生效的为准（本脚本刻意用**最低优先级、不用 `!important`**，站点自己的配色优先）
- 设置存在哪 → 本机脚本管理器里，清浏览器数据／换浏览器会丢

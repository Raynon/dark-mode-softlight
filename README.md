# 暗黑模式 · 大面积文案柔光降白

一个单文件油猴脚本（userscript）：把**深色模式**页面的**大面积正文压暗**（默认降到 80% 亮度），
同时严格保护链接、按钮、输入框、高亮、代码块、黑幕与透明文字。

> 设计取向：**宁可漏压，不可误伤。**

| | |
| --- | --- |
| **安装** | <https://greasyfork.org/scripts/588400> |
| **版本** | 见脚本头部 `@version`（不在此处重复，避免文档与代码漂移） |
| **依赖 / 构建** | **无**。纯 vanilla JavaScript，单文件，无 `package.json`、无编译步骤 |
| **生效范围** | `@match *://*/*` —— 所有网站 |
| **许可** | MIT |

## 它怎么工作

只做一件事：往页面注入一个 `<style>`，把文字颜色改成 `hsl(0, 0%, N%)`。

```css
@media (prefers-color-scheme: dark) {          /* 只在深色模式下生效 */
  :root { color: hsl(0, 0%, N%) !important; }
  :is(<文字容器白名单>):not(:is(<排除列表>)) {
    color: hsl(0, 0%, N%) !important;
  }
}
```

| 要素 | 内容 |
| --- | --- |
| **白名单**（会被压暗） | `body div p span li h1–h6 td th label strong figcaption blockquote dt dd article section main aside` |
| **排除列表**（受保护） | `a`、`button`、`input`、`textarea`、`em`、`code`、`.heimu`、任何 `style` 含 `transparent` 的元素，以及脚本自己的浮层 |
| **生效条件** | 页面处于深色模式（`prefers-color-scheme: dark`）。浅色模式下脚本存在，但**没有任何视觉变化** |
| **默认亮度** | 80%，可按站点单独调整（10–100） |
| **幂等** | `apply()` 每次先移除旧的 `<style>` 再插入，可反复调用 |

## 安装

1. 先装一个用户脚本管理器（Tampermonkey、Violentmonkey 等）
2. 打开 <https://greasyfork.org/scripts/588400> 点安装

## 用法

装好后，在脚本管理器的菜单里有两个命令：

| 菜单 | 作用 |
| --- | --- |
| `🔆 全站文字亮度` | 调整**当前站点**的亮度：浮层里输入 10–100，确认后写回 |
| `🚫 本页压暗开关` | 把**当前页面**加入／移出"不压暗"名单，并立即生效 |

亮度按**站点**（host）保存；"是否压暗"按**页面**（`origin + pathname`）保存 —— 同一个站的不同路径要分别关闭。

## 已知边界

- **只改文字颜色，不动背景**；并且强制中性灰，会抹掉站点深色主题原本的色偏。
- **判定依据是系统／浏览器的深色模式，不是页面实际底色。** 固定浅色主题的站点会被误压暗 —— 请用 `🚫 本页压暗开关` 手动关掉。不做自动底色探测，那等于重造一个 dark mode。
- `[style*="transparent"]` 是**子串匹配**：容器上写了 `background: transparent` 会连带保护**整棵子树**，使该区域内的正文不被压暗（已知问题，暂不处理）。
- **SPA（前端路由）切换后不会自动重算**，需要再点一次菜单。
- **不专门处理 Shadow DOM**：注入的样式表不进入 shadow 树内部，只有 `:root` 的继承色能渗进去；组件内部自带颜色的文字不会被压暗。
- 与站点自带的深色主题、其它同类脚本**可能互相覆盖**（都用 `!important`）。
- 由于使用白名单／排除列表，改这两份名单的**影响面是"所有网站"**，改动前请想清楚。

## 仓库说明

本仓库保存**两份内容完全相同**的脚本，只是文件名不同：

| 文件 | 用途 |
| --- | --- |
| `dark-mode-softlight.user.js` | **GreasyFork 同步用**（同步 URL 指向它） |
| `暗黑模式-柔光降白.user.js` | 同一份内容，保留原有的中文文件名 |

两份必须**永远字节相同**：GreasyFork 的同步 URL 里路径是百分号编码的，而 webhook 推送时 payload 里的路径是原始 UTF-8；
用 ASCII 文件名作为同步目标可以避免两边格式不一致导致匹配不上。
